# CT-07: Verificação da Página de Casos de Teste

**Suíte de Testes:** Navegação / Casos de Teste  
**Prioridade:** Média  
**Tipo de Teste:** Funcional / Interface (UI)  

---

### Pré-condições
1. O navegador deve estar aberto na URL base (`https://automationexercise.com`).
2. A página inicial deve carregar completamente.

---

### Dados do Teste
* *Não se aplica (teste exclusivo de navegação).*

---

### Passos de Execução
1. Navegar até a URL base (`https://automationexercise.com`).
2. Validar se a homepage está visível e foi carregada com sucesso.
3. Clicar no botão **Test Cases** no menu superior.
4. Validar se o usuário foi redirecionado com sucesso para a página `/test_cases`.
5. Validar se o cabeçalho **'TEST CASES'** está visível na tela.

---

### Resultado Esperado
O usuário navega com sucesso para a página de casos de teste a partir do botão 'Test Cases' na barra de navegação principal, confirmando a correta exibição da página e da URL.
